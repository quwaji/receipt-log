# GCP 利用状況・課金確認手順

このドキュメントでは、receipt-log プロジェクトで使用している GCP サービス（Cloud Run、Gemini API、Google Sheets API）の利用状況と課金を確認する方法をまとめています。

## Google Cloud Console へのアクセス

1. [Google Cloud Console](https://console.cloud.google.com/) にアクセス
2. GCP アカウントでログイン
3. プロジェクト選択ドロップダウンから receipt-log プロジェクトを選択

## 課金情報の確認

### 全体的な課金状況を確認

1. サイドバーメニューから **「請求」** → **「概要」** をクリック
2. 以下の情報が表示されます：
   - 当月の推定費用
   - 前月の実費用
   - 課金状況の推移グラフ

### 詳細な費用内訳を確認

1. **「請求」** → **「費用**」 をクリック
2. フィルタ条件で以下を指定：
   - サービス：表示したい API を選択（Gemini API、Cloud Run、Sheets API など）
   - 日付範囲：確認したい期間を選択
3. 日ごと、またはサービスごとの費用がグラフや表で表示されます

## API ごとの利用状況確認

### Gemini API の利用状況

1. サイドバーから **「APIs と サービス」** をクリック
2. **「資格情報」** タブで API キーを確認
3. **「ライブラリ」** から「Generative AI API」を検索して、ステータスを確認
4. 利用状況の詳細：
   - **「請求」** → **「費用分析」** で「API」フィルタを適用
   - 「Generative AI API」を選択して、トークン使用量や費用を確認

### Google Sheets API の利用状況

1. **「APIs と サービス」** → **「ライブラリ」**
2. 「Google Sheets API」を検索して有効状態を確認
3. 利用状況：
   - **「請求」** → **「費用分析」** で「Google Sheets API」を選択
   - API コール数と費用を確認

## Cloud Run の利用状況確認

### Cloud Run サービスの詳細情報

1. サイドバーから **「Cloud Run」** をクリック
2. デプロイされているサービス一覧が表示されます
3. サービスをクリックして詳細を確認：
   - リビジョン履歴
   - トラフィック配分
   - デプロイ時刻

### Cloud Run の利用統計

1. Cloud Run のサービス詳細ページ上部の **「メトリクス」** タブをクリック
2. 以下の情報が表示されます：
   - リクエスト数
   - レイテンシ
   - エラー率
   - メモリ使用量

### Cloud Run の費用確認

1. **「請求」** → **「費用分析」** をクリック
2. サービスフィルタで「Cloud Run」を選択
3. 以下の費用が表示されます：
   - vCPU-seconds（CPU 使用時間）
   - Memory-seconds（メモリ使用時間）
   - リクエスト処理数

## 予算アラート設定

過度な費用を避けるため、予算アラートを設定することをお勧めします。

### アラートの設定方法

1. **「請求」** → **「予算」** をクリック
2. **「予算を作成」** をクリック
3. 以下の項目を設定：
   - **予算名**：例）「receipt-log 月間予算」
   - **予算金額**：月ごとの予算上限を入力（例：$50）
   - **期間**：「月単位」を選択
4. **「次へ」** をクリック
5. **「通知ルール」** で以下を設定：
   - 80%に達したときにアラート（予算の80%を使用時）
   - 100%に達したときにアラート（予算上限に達した時）
   - メールアドレスの提供
6. **「完成」** をクリック

## よくある確認項目

| 項目 | 確認方法 |
|------|---------|
| 今月の合計費用 | 請求 > 概要 |
| Gemini API の使用トークン数 | 請求 > 費用分析（Generative AI API） |
| Cloud Run のリクエスト数 | Cloud Run > メトリクス |
| Sheets API の API コール数 | 請求 > 費用分析（Google Sheets API） |
| 費用推移グラフ | 請求 > 概要（グラフ表示） |

## 注意事項

- GCP は使用状況が反映されるまで数時間から 24 時間のラグがあります
- 日次レポートは太平洋標準時（PST）の翌日午前 3 時に生成されます
- 予測費用はあくまで推定値であり、実費用とは異なる場合があります
- 定期的な確認（週 1 回程度）をお勧めします
